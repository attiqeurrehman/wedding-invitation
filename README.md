# Wedding Invitation Website 💕

A beautiful and romantic wedding invitation website featuring elegant design, smooth animations, and interactive elements.

## ✨ Features

- **Beautiful Hero Section**: Elegant gradient background with romantic typography and animated hearts
- **Save The Date**: Clear display of wedding date, time, and venue information
- **Our Story**: Timeline showcasing the couple's journey with emoji icons and hover effects
- **Wedding Schedule**: Detailed timeline of the wedding day events
- **Interactive RSVP Form**: Functional form with validation and confirmation messages
- **Responsive Design**: Optimized for all devices (desktop, tablet, and mobile)
- **Romantic Animations**: Floating hearts, fade-in effects, and smooth transitions
- **Modern Styling**: Uses Google Fonts (Great Vibes, Playfair Display, Montserrat)

## 🎨 Design Elements

- Romantic color palette with soft pinks, roses, and warm gradients
- Elegant cursive fonts for names and headings
- Smooth scroll animations and parallax effects
- Pulsing heart animations
- Interactive form elements with focus states
- Box shadows and rounded corners for depth

## 🚀 Getting Started

### Viewing the Website

Simply open `index.html` in a web browser to view the wedding invitation website.

### Using a Local Server

For the best experience, serve the files using a local web server:

```bash
# Using Python 3
python3 -m http.server 8080

# Using Node.js (with npx)
npx http-server -p 8080

# Using PHP
php -S localhost:8080
```

Then navigate to `http://localhost:8080/index.html` in your browser.

## 🎯 Customization

To customize the wedding invitation for your own use:

1. **Update Names**: Edit the names "Sarah" and "James" in `index.html`
2. **Change Date & Venue**: Modify the date, time, and location details
3. **Personalize Story**: Update the "Our Story" section with your own timeline
4. **Adjust Colors**: Change CSS variables in `styles.css`:
   - `--primary-color`
   - `--secondary-color`
   - `--accent-color`
5. **Modify Schedule**: Update wedding day timeline events
6. **RSVP Handling**: Connect the form to your backend or email service

## 💌 RSVP Form

The RSVP form includes:
- Name input
- Email input
- Attendance selection (Joyfully Accepts / Regretfully Declines)
- Number of guests
- Special message or dietary requirements
- Client-side validation
- Confirmation alert

**Note**: Currently, the form displays a confirmation message. To collect RSVPs, integrate with a backend service or email handler.
